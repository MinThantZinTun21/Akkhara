# Myanmar output is Unicode only, with no Zawgyi mode

The keyboard commits standard Unicode Myanmar text and has no Zawgyi output mode. Unicode is the default on every current Android version, and a Zawgyi mode would double the Myanmar layout, the composing rules and the test surface for an encoding that is being retired. Anyone asking for Zawgyi later should treat it as a separate layout with its own spec, not a toggle on this one.
