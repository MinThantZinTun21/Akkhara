# Android's DownloadManager downloads the models, so a download outlives the app

ADR 0004 chose the app's own foreground service over Android's `DownloadManager`. On the owner's TECNO (HiOS 16, Android 16), swiping Akkhara away from recent apps kills its process ("Swipe-up clean"), and the download and its notification die with it. The owner wants a model download to keep going and stay in a notification whatever happens to the app, Force stop included. Only `DownloadManager` does that: it runs in a system process, not the app's. This ADR replaces ADR 0004's choice of downloader; the rest of ADR 0004 and ADR 0005 stands: listed files only, pinned and checked by SHA-256, Wi-Fi only, one at a time, the open check, and no other network use.

- **The system downloads, the app asks.** The app hands `DownloadManager` the pinned URL of a listed model, Wi-Fi only. The app itself opens no network connection; it keeps the `INTERNET` permission only because `DownloadManager` requires it of the app that asks. No other feature may use the network (ADR 0002).
- **The system's notification.** While it downloads, Android shows its own notification with the progress. It has no Cancel button; Cancel is in the app. When the file is complete and checked, the app's own notification says the model is ready, or why it failed.
- **The file stays where it lands.** `DownloadManager` can only write to the app's folder on shared storage (`Android/data/com.akkhara.keyboard/files`), so downloaded models stay there instead of being copied into private storage, which would need the same space again. Other apps cannot read that folder on Android 11 and later, and it is deleted with the app. Models already in private storage, and imported ones, stay where they are.
- **Checked as soon as it completes.** When the download completes, the app checks the SHA-256 and that the file opens as a model in the background, without the app being open. After Force stop Android does not tell the app, so the check waits until the app next opens.
- **Starting over.** Partial files from the old downloader cannot be continued, so they are deleted.

We kept the app's own service as the alternative, made to restart itself or run as a user-initiated data transfer job on Android 14 and later. It keeps ADR 0004's Cancel in the notification and private storage, but cannot survive Force stop, which the owner wanted.
